Si bien es cierto que para ser un buen desarrollador o diseñador web debes aprender las bases, eso no significa que tengas que escribir desde cero cada línea de código de todas las páginas que hagas.

Hoy en día existen muchas herramientas que nos ayudan a tener un flujo de trabajo más eficiente y a desarrollar proyectos en menos tiempo. Entre ellas están los frameworks.

Un framework es una estructura de trabajo que nos proporciona herramientas y soluciones ya preparadas para construir una página o una aplicación web.

Imagínate que eres constructor y tienes que levantar una pared. Podrías construirla desde cero, colocando cada ladrillo, o podrías utilizar una pared prefabricada que ya está lista para instalar. Ambas opciones pueden servir, pero la segunda te permite avanzar más rápido.

De forma parecida, un framework nos ofrece una base sobre la cual podemos construir. Así podemos dedicar más tiempo a resolver las necesidades particulares de cada proyecto.

Esto no quiere decir que debamos usar un framework para todo. Lo importante es conocer las bases y elegir las herramientas que mejor se adapten a lo que necesitamos hacer.
